节点就是跑虚拟机的机器。没节点，后面都开不了机。

## 集群节点

菜单位置：`节点管理 → 集群节点`

这里主要干三件事：

- 加节点
- 改节点信息
- 删节点 / 停用节点

### 加节点

点添加，一般填这些：

- 显示名称
- 主机地址
- 节点名称

加成功后，开虚拟机时就能选到它。

![节点列表](https://img.xwyue.com/i/2026/07/27/6a672cb88e09c.png)

![添加节点](https://img.xwyue.com/i/2026/07/27/6a672cd2e0e01.png)

节点详情里还能管这台机器的网卡。

## 负载信息

菜单位置：`节点管理 → 负载信息`

选一个节点，看它现在忙不忙。  
CPU、内存顶满了就别再往上面塞机器。

![节点负载](https://img.xwyue.com/i/2026/07/27/6a672d8f261f4.png)

## SDN 管理

菜单位置：`节点管理 → SDN管理`

普通桥接够用就先别管。  
真要做更复杂的网络隔离，再来这里：

- 加 SDN 区域
- 加 VNet
- 加子网
- 需要的话配 IPAM

![SDN管理](https://img.xwyue.com/i/2026/07/27/6a672daabbdcd.png)

## 建议你怎么用

1. 被控装好后，先把节点加进来
2. 开机器前先看一眼负载
3. 网络不复杂，就别一上来搞 SDN
