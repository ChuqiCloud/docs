初始化脚本就是开机后自动执行的配置。装软件、改主机名、写配置，都能放这里。

## 怎么用

菜单位置：`初始化脚本`

- 按名称搜索
- 新建脚本
- 编辑脚本
- 删除脚本
- 选中后手动执行

新建时至少填两样：

- 脚本名称
- 脚本内容

## 和开机器的关系

创建虚拟机时可以直接挂脚本。  
机器起来后自动跑，少做一遍手工初始化。

## 建议你怎么用

1. Linux 和 Windows 脚本分开写
2. 先拿测试机跑通，再给正式业务用
3. 改完脚本记一下适用系统，别后面自己也忘了
4. 执行失败先看任务结果，再回头查脚本内容
