系统设置主要就是改各项默认值和全局参数，改完点保存才生效。

菜单位置：`系统设置`

![系统设置](https://img.xwyue.com/i/2026/07/27/6a672ed771adf.png)

## 能改什么

### 存储默认设置

- **Linux 系统磁盘大小**：新开 Linux 机器时的默认系统盘
- **Windows 系统磁盘大小**：新开 Windows 机器时的默认系统盘

只影响之后新建的机器，已经开好的不会变。

### 系统 IO 默认设置

- **IO 限制**：限制迁移、备份这类后台任务的读写速度  
  设低一点，后台任务就不容易把盘打满。

### VNC 设置

- **VNC 超时时间**：远程桌面多久没操作自动断

### 回收站设置

- **回收站保留时间**：机器删进回收站后留几天  
  到期会自动彻底删除。  
  太短容易来不及恢复，太长回收站会越堆越多。

### 系统令牌

这里的 **认证令牌 / 系统令牌** 很关键。

被控安装绑主控时，要填的就是这个令牌。

- 可在页面直接复制
- 改了之后，已经装好的被控、以及还在用旧令牌的外部对接，都可能要同步更新
- 别随意外传

被控怎么填，看 [被控安装](/docs/qimenidc/installation/agent)。

## 使用注意

1. 改的是默认值和全局行为，不是某一台机器的配置
2. 有未保存更改时先保存，再去验证
3. 系统令牌一改，被控绑定和外部调用都要跟着改
