镜像就是装机用的系统。没有镜像，开不了机，也重装不了。

## 系统模板

菜单位置：`镜像管理`

这里可以：

- 看已有系统
- 添加 / 修改 / 删除模板
- 把镜像下载到指定节点

镜像只在主控有还不够，目标节点也得有，开机器才稳。

![镜像列表](https://img.xwyue.com/i/2026/07/27/6a672dcb0c645.png)

![添加或编辑镜像](https://img.xwyue.com/i/2026/07/27/6a672de4ee7a0.png)

## 在线系统列表

菜单位置：`镜像管理 → 在线系统列表`

不想自己传包，就从在线列表里直接导入常用系统。

![在线系统列表](https://img.xwyue.com/i/2026/07/27/6a672e034c522.png)

## 建议你怎么用

1. 先把常用系统备齐，比如 Debian、Ubuntu
2. 新镜像先拿一台测试机验证
3. 多节点的话，用到的节点都下载一份
4. 不用的老镜像及时删，别越积越多
