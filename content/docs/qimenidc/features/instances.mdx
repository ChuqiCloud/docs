实例管理就是管虚拟机：开、关、重装、回收。

## 虚拟机

菜单位置：`实例管理 → 虚拟机`

### 列表页

- 用主机名或 IP 搜索
- 看机器在哪个节点、哪个地区
- 直接创建虚拟机
- 删了的机器会进回收站

![虚拟机列表](https://img.xwyue.com/i/2026/07/27/6a67294948c35.png)

### 怎么开一台机器

点 **创建虚拟机**，按下面填：

1. 选节点
2. 有模板就选模板，没有就手填配置
3. 设密码；磁盘不填就用镜像默认大小
4. 需要开机自动初始化，就挂初始化脚本
5. 提交后等任务跑完

![创建虚拟机](https://img.xwyue.com/i/2026/07/27/6a6729747e168.png)
![创建虚拟机](https://img.xwyue.com/i/2026/07/27/6a6729a12e533.png)

### 详情页能干什么

点进某台机器后，常见操作都在这里：

- 开机 / 关机 / 重启 / 重装
- 开 VNC
- 改配置
- 管 IP、NAT
- 做快照、备份、恢复备份
- 加流量包
- 迁移

![实例详情](https://img.xwyue.com/i/2026/07/27/6a672a26321eb.png)

## 实例迁移

菜单位置：`实例管理 → 虚拟机 → 实例详情 → 迁移`

把这台机器迁到别的节点时，走这里。

### 迁之前先看

- 机器还在跑的话，页面会提醒你先关机
- 目标节点不能是当前节点
- 目标节点要有足够资源和对应存储

### 怎么迁

1. 进实例详情，点迁移
2. 选 **目标节点**
3. **目标 VMID** 不填就沿用原来的
4. **目标存储** 按目标节点实际存储填，比如 `hddhome`
5. **备份目录** 一般用默认即可
6. 需要迁完自动开机，打开 **迁移后启动**
7. 点 **创建迁移任务**

![实例迁移](https://img.xwyue.com/i/2026/07/27/6a672b7a374b6.png)

### 任务进度

创建后下面会出迁移任务：

- 状态：等待刷新 / 迁移中 / 已完成 / 失败
- 阶段
- 进度百分比

页面会自动刷新；也可以手动点刷新。失败了看错误信息，别急着重提。

### 注意

1. 先关机再迁，最稳
2. 目标存储名填错，任务会挂
3. 迁的过程中别同时改这台机器配置
4. 完成后再回列表确认节点是不是已经变了

## 回收站

菜单位置：`实例管理 → 回收站`

删错了先来这里：

- **恢复虚拟机**：捞回来
- **强制删除**：彻底删掉，回不来

![回收站](https://img.xwyue.com/i/2026/07/27/6a672a6226251.png)

## 配置模板

菜单位置：`实例管理 → 配置模板`

把常用配置存成模板，下次开机器直接套，不用每次重填。

可以新建、编辑、删除模板。

![配置模板](https://img.xwyue.com/i/2026/07/27/6a672a86dc87a.png)

## 建议你怎么用

1. 节点、镜像、IP 池先准备好
2. 常用规格先做成模板
3. 用模板开机器
4. 网络、快照这些进详情页再调
5. 不用的机器先丢回收站，确认没问题再永久删除
