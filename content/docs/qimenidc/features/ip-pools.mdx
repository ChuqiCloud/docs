IP 池就是给虚拟机发地址的地方。池里没 IP，机器就分不到网。

## 地址池列表

菜单位置：`IP池管理`

你可以：

- 建 IPv4 / IPv6 池
- 改池信息
- 删池
- 把池绑到节点
- 配 NAT 地址和 NAT 桥接

注意几条硬规则：

- IPv4 池只能填 IPv4 网关
- IPv6 池只能填 IPv6 网关
- 同一个 NAT 地址 / NAT 桥接，别让多个节点抢

## 地址池详情

点进某个池之后：

- 加 IP 段
- 改单条 IP
- 删 IP
- 按 IP、后缀、虚拟机 ID 搜

主要看两件事：还有没有空闲 IP，以及某个 IP 绑给了哪台机器。

![地址池详情](https://img.xwyue.com/i/2026/07/27/6a672c6f4f0bb.png)

## 建议你怎么用

1. 按机房或业务拆池，别全塞一个池里
2. 开机器前先看池里还有没有空地址
3. 机器删了以后，回来确认 IP 有没有释放
4. 要用 NAT，先把节点上的地址和桥接规划好
