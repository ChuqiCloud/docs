## 一键安装命令

```bash
wget -O install.sh http://mirror.chuqiyun.com/software/QAgent/install.sh && bash install.sh
```

### 填写主控系统令牌

被控装完后，需要绑定主控的 **系统令牌**。

这个令牌在主控里：

`系统设置 → 系统令牌 / 认证令牌`

复制后，在被控安装命令行提示的位置粘贴即可完成绑定。

![填写主控系统令牌](https://img.xwyue.com/i/2026/04/05/69d1d73febff0.png)

按图片位置复制，再粘贴到命令行。

如果后面在系统设置里改了令牌，已绑定的被控可能要重新处理，否则会连不上主控。
