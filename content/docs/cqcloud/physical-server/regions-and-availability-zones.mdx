## 如何选择服务器

购买物理服务器时，请结合以下因素合理选择地域。若不慎选错地域，可在正确地域节点重新购买服务器，并申请当前地域服务器退款。

| 考虑因素 | 选择说明 |
| --- | --- |
| 地域与可用区 | 用户与资源部署地域距离越近，网络时延通常越低，访问速度越快。请结合业务场景对时延的要求选择地域。 |
| 产品价格 | 各地域的成本和产品特性不同，资源价格可能存在差异。活动时效和优惠政策也可能影响价格，请以速维云产品购买页的价格信息为准。 |
| 线路区别 | 境内地域提供电信、联通、移动及 BGP 等线路，建议根据用户运营商选择。单线服务器跨网、跨省访问可能受到运营商策略限速。境外服务器提供国际、大陆优化等线路，请根据业务需求选择。 |
| 产品特性 | 境内服务器建站需要使用备案域名，域名白名单支持自动过白、人工过白、自助过白等方式，部分地域支持 ICP 备案。部分地域支持 25 邮件端口、IPv6、DDoS 高防等服务，请按需选择。 |
