## 相关材料

### 身份证件

- 身份证需提供正反面，即证件人像页和国徽页；护照仅需提供人像页。
- 证件文字需正向展示，证件边角完整，避免留白过大。
- 仅允许上传原件拍摄的照片，不允许添加水印，不支持扫描件。
- 仅支持 JPG 和 PNG 格式，单个文件不大于 3 MB。
- 图片最短边像素尺寸不得小于 400，最长边像素尺寸不得大于 3000。
- 证件有效期需大于 3 个月。
