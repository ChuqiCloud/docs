# 域名白名单说明

<Callout>
只有中国大陆地区的服务器需要过白备案域名，境外地区服务器均无需过白域名。
</Callout>

## 弹性云服务器

### 过白类型说明

#### 自动过白备案域名

已备案的域名将自动过白，无需联系客服处理。新备案域名的过白可能存在延迟。

#### 人工过白备案域名

需联系客服并提供服务器 IP 及已备案域名，人工过白后方可正常访问。仅需过白顶级域名，即可通用于其所有二级域名。

#### 人工过白二级域名

需联系客服并提供服务器 IP 及所有需要使用的已备案二级域名，人工过白后方可正常访问。未过白的二级域名即使已备案，仍会被拦截。
