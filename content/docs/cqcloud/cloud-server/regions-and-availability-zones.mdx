# 地域与可用区

本文主要介绍云服务器目前支持的地域、可用区与节点特性。

## ECS 弹性云

### 如何选择 ECS 弹性云

购买 ECS 弹性云时，请结合业务需求选择地域。若误选地域，可在正确地域重新购买服务器，并对原地域服务器申请退款。

|考虑因素|选择说明|
|---|---|
|地域与可用区|用户与资源部署地域距离越近，网络时延通常越低，访问速度越快。建议根据业务对时延的要求选择地域。|
|产品价格|不同地域的资源成本和产品特性不同，价格可能存在差异；活动与优惠政策变化也会影响价格，可优先选择价格更合适的地域。|
|线路区别|境内地域提供电信、联通、移动、BGP 等线路，建议根据用户运营商选择。单线服务器跨网、跨省访问可能受运营商策略限速。境外地域提供国际、大陆优化等线路，应根据业务访问需求选择。|
|产品特性|境内建站需使用已备案域名，域名白名单可能采用自动、人工或自助方式处理；部分地域可进行 ICP 备案。部分节点支持 25 邮件端口、IPv6、DDoS 高防等能力。|

</Callout>

## LH 轻量云

<Callout>
LH 轻量云不支持升降级配置和购买流量包；40G 硬盘以下的配置无法安装 Windows 系统；不支持配置内网。
</Callout>
