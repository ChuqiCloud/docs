# 产品概述

初七云提供面向通用计算、轻量应用、境外业务和高性能计算场景的云服务器产品。本文介绍 ECS 弹性云、LH 轻量云、PCS 套餐云与 GC 游戏云的产品定位、适用场景和使用限制，帮助您选择合适的云服务器类型。

## 云服务器类型

初七云目前提供以下四类云服务器产品，更多系列敬请期待。

|类型|产品定位|适用场景|
|---|---|---|
|ECS 弹性云|常规型云服务器，支持弹性升降级、控制台 VNC 等功能。|需要灵活调整配置，或对地域、线路有选择需求的业务。|
|LH 轻量云|按预设套餐规格售卖的轻量型云服务器，可快速完成选配。|个人站点、店铺管理、开发测试、学习环境及轻量应用。|
|PCS 套餐云|面向境外部署的套餐云资源，包含跨境电商-双 ISP 与境外两类套餐。|境外建站、跨境电商及其他电商业务。|
|GC 游戏云|采用高主频 CPU 的高性能云服务器。|游戏服务及其他对处理器性能要求较高的业务。|

## 选择建议

- 需要灵活配置、弹性调整或多线路选择时，选择 ECS 弹性云。
- 需要快速部署轻量应用，且配置需求相对固定时，选择 LH 轻量云。
- 需要面向境外建站或跨境电商业务时，选择 PCS 套餐云。
- 需要高主频 CPU 支撑游戏或计算密集型业务时，选择 GC 游戏云。

## ECS 弹性云

ECS 弹性云属于常规型云服务器，提供多个地区和线路选择。不同节点的资源特性有所差异，可根据业务需求选择合适的节点与配置。

### 核心特性

- 支持弹性升降级，便于根据业务规模调整资源配置。
- 支持控制台 VNC 等常用管理功能，满足日常运维需求。
- 可选择不同地区和线路，适用于对部署位置、访问路径有明确要求的业务。

### ECS 弹性云-大带宽

本大带宽服务器套餐内公网带宽规格为出、入方向公网带宽的峰值上限，不作为业务承诺指标。当初七云在业务高峰期出现资源争抢时，公网带宽可能会受到限制，因此不适用于对公网带宽稳定性有强保障诉求的场景。

## LH 轻量云

LH 轻量云面向中小企业、个人开发者和学生，适用于云端构建、个人站点、店铺管理、开发测试及学习环境。产品以套餐形式提供固定规格的云资源，用户可一键选购，无需进行复杂配置。

适合对部署效率和使用便利性要求较高、资源需求相对稳定的业务。对于需要频繁调整配置或保障性能与网络质量的场景，建议优先评估 ECS 弹性云。

### LH 常规轻量云

#### 使用规则

- 系统盘生命周期与轻量云主机一致，随主机一同购买并作为系统盘使用，不支持挂载或卸载。
- 默认配置一个公网 IP，不支持更换；云主机到期后不支持保留该 IP。
- 不保障服务器性能及网络质量。不得长时间占用服务器资源或带宽，否则可能被限制、封禁或清退。
- 实际使用流量超过套餐月流量包限额后，轻量云将暂停并强制关机，不支持通过购买流量包恢复。

## PCS 套餐云

PCS 套餐云面向境外部署，包含跨境电商-双 ISP 与境外两类套餐。产品采用套餐化资源配置，适合需要快速部署境外站点或开展跨境业务的用户。

|套餐类型|定位|适用场景|
|---|---|---|
|跨境电商-双 ISP|面向跨境电商业务的双 ISP 套餐资源。|TK 直播合规推流、多店铺安全托管、社媒养号代运营等。|
|境外|面向一般境外业务部署的套餐资源。|境外建站及相关业务部署。|

### 跨境电商-双 ISP

- IP 资源采购自各地优质本土运营商，可满足 TK 直播合规推流、多店铺安全托管、社媒养号代运营等业务需求。
- 资源创建后，如删除资源，当前计费周期内剩余使用时长不予退费。
- 受国家政策及合规要求限制，资源创建后不支持与国内 IP 直连。

### 境外

境外套餐面向境外建站场景，适合部署企业官网、个人站点及其他一般性境外业务。

## GC 游戏云

GC 游戏云面向游戏及其他对处理器性能要求较高的业务，采用 R9-9950X、i9-14900K 等高主频 CPU，以满足高频计算需求。

### 核心特性

- 支持固定带宽和按流量两种计费方式，可根据业务流量特征选择。
- 采用高主频 CPU，适用于游戏服务及其他对单核性能、处理器频率有较高要求的业务。
