ExtraLink AI 提供两种使用方式：按量付费（余额）和订阅套餐。

## 按量付费（余额）

- 适用场景：使用量较小且不固定，按实际消耗付费。
- 充值方式：进入“充值/订阅”页面，选择充值金额并完成支付；额度会即时到账，可在右上角查看余额。
- 费用计算：根据实际 API 调用消耗扣除余额。

## 订阅套餐

- 适用场景：长期固定的 Token 使用。购买套餐可享受额度与分组倍率的双重折扣。
- 订阅方式：进入“充值/订阅”页面，切换至订阅页面，选择适合的套餐并完成支付；套餐即时生效，可在“我的订阅”页面查看。
- 套餐特点：套餐内额度独立计算，不与余额混用。
- 套餐限制：套餐购买以该套餐周期（日、周、月）的总额度为准；更短周期的限额仅用于阶段性的号池保护。

优先选择站内充值。如为政企用户，请私信客服联系。

## 消费价格说明

### 1. 额度定价

- 本站余额充值比例为 1:1，即 1 元人民币 = 1 美元站内额度。
- GPT 类套餐的折扣比例约为 8 折起，Claude 类套餐的额度比例为 7.5 折起。

### 2. 消费定价

- 所有模型的基础计价与官方 API 价格同步一致，作为扣费基准价格（1 倍率）。
- 实际消费根据不同分组的倍率进行扣费。
- 示例：用户选择 0.05 倍率分组，消费的 Token 基准价格为 2 美元，则账户实际扣费为 `2 × 0.05 = 0.1` 美元，即 0.1 元人民币。

### 3. 套餐与余额的差异

- 订阅套餐的整体消费价格低于余额结算，但受阶段性使用限额限制。
- 订阅套餐的消费倍率通常优于余额结算。
