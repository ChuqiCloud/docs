---
title: 3.2 基础参数说明
description: AI API 客户端的基础配置项
---

不同分组的 API Key 对应不同的请求基础参数。配置客户端时，需要填写以下信息：

|参数名称|说明|示例|
|---|---|---|
|API Key|创建的 API Key。|`sk-xxxxxxxxxxxxxxxx`|
|Base URL|API 请求地址，不同分组可能有所差异。|`https://apis.extralink.net`|
|Model|当前分组可用的模型名称。|`gpt-5.5`、`claude-opus-4-8` 等；具体名称可在“模型广场”查看。|
