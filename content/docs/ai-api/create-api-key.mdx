# 第二步：创建 API Key

API Key 是访问 ExtraLink AI 服务的凭证。请根据付费方式创建对应类型的 API Key。

API Key 会绑定不同分组，可使用该分组提供的模型。不同分组支持的模型、模型来源和定价均可能不同。

## 创建步骤

1. 登录后进入 [API 密钥](https://apis.extralink.net/keys) 页面。
2. 点击“创建密钥”按钮。
3. 填写 API Key 名称，可按项目或客户端用途命名以便识别。
4. 选择所需的分组。

<img
  src="https://img.xwyue.com/v/2026/08/11/6a7aa3a0ec4f1.png"
  alt="创建 API Key 时选择分组"
  className="rounded-lg border border-fd-border"
/>

5. 点击“创建”，复制生成的 API Key。

可以创建多个 API Key，分别用于不同项目、客户端或模型。请妥善保存密钥，避免提交至代码仓库或公开分享。
