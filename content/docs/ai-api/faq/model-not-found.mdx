---
title: 2.2 CCS 使用中出现 model_not_found 错误
description: 排查 CCS 调用时的 model_not_found 错误
---

## 可能原因

- 模型名称填写错误。
- API Key 绑定的分组不支持该模型。
- CCS 自身出现问题。

## 解决方法

1. 检查模型名称是否正确：可在站内“模型广场”获取具体名称。
2. 确认分组支持该模型：同一类分组可访问的模型完全一致，只需确认分组是否正确。例如，不要在 OpenAI 分组请求 Claude 系列模型。
3. 关闭后重新打开本地路由开关。
4. 重启当前客户端。
5. 新建一个 session。
