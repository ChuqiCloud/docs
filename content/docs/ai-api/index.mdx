# 快速上手

完成余额充值或套餐订阅并创建 API Key 后，即可在客户端中调用 AI API。

## 什么是中转站

中转站为多个 AI 模型服务提供统一的 API 接入入口。客户端只需配置一次 API 地址和 API Key，即可按需调用不同模型，无需分别对接多个上游服务。

## 使用优势

- 统一接入：使用兼容的 API 方式管理不同模型，减少客户端配置成本。
- 灵活选择：可根据任务需求选择合适的模型和分组倍率。
- 集中管理：余额、套餐、密钥和调用使用情况均在同一平台管理。
- 便于切换：更换模型或调整分组时，无需重新配置多个服务商账号。

## 接入流程

1. 充值余额或订阅套餐。
2. 创建 API Key。
3. 在客户端中完成配置。
